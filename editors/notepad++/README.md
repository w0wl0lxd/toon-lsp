# TOON — Notepad++

This integration provides syntax highlighting only. Notepad++ does not support LSP.

## Setup

1. Open Notepad++.
2. Go to Language → User Defined Language → Define your language.
3. Click Import and select `toon-udl.xml` from this directory.
4. Restart Notepad++.
5. Open a `.toon` file and confirm highlighting applies.

See [IDE support](../../docs/ide-support.md) for editors with full LSP support.
