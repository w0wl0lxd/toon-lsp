# TOON — JetBrains IDEs

Works with IntelliJ IDEA, WebStorm, PyCharm, and other JetBrains IDEs (2024.2+).

## Install

1. Open Settings > Plugins > Marketplace.
2. Search for "TOON Language".
3. Click Install and restart the IDE.

The plugin bundles the toon-lsp binary. You need no PATH setup.

Alternative: download the JAR from [Releases](https://github.com/w0wl0lxd/toon-lsp/releases) and install it via Settings > Plugins > Install Plugin from Disk.

## Verify

Open a `.toon` file. Check that diagnostics, hover, and completion work.

See [IDE Support](../../docs/ide-support.md) for all features.
